# 用户完整操作流程梳理

> 符号说明：`[按钮]` 页面内按钮；`【页面】` 八页结构；`(弹窗)` 弹窗提示

## 一、首次启动流程（新用户引导，约 60 秒完成核心闭环）

```
安装应用 → 打开 App
  → 【页面1 启动权限引导首页】
  → 系统弹出「允许 FlowLume 访问通知」→ 用户点【允许】
  → 点击 [设置壁纸] → 跳转系统壁纸选择器 → 选中 FlowLume → 设为壁纸
  → 返回 App → 播放任意音乐（Apple Music / Spotify 等）
  → 状态面板出现「正在播放：《歌名》 - 歌手」
  → 首页缩略预览实时渲染流体光影
  → 完成！桌面已流动起来
```

**分支 A：用户跳过音频权限**
```
→ 首页 [允许获取音频权限(可选)] 未开启
→ 状态面板显示「未开启音频联动，仅展示封面流体」
→ 不影响壁纸基本功能；可在设置中随时补开
```

**分支 B：用户未播放音乐**
```
→ 首页状态面板显示「未检测到播放中的音乐」
→ 壁纸使用【默认色调】渲染纯净流体
```

## 二、日常使用流程（老用户）

### 2.1 切换渲染模式 / 调参
```
打开 App
 → 首页底部形态切换入口 → 切换到【桌面壁纸模式】或【App全屏模式】
 → 进入【页面2 通用渲染参数面板】
 → 调节流体缩放、流动速度
 → 切换 BLUR / FLUTED GLASS 渲染模式
 → 调节全局亮度、色彩饱和度
 → 变更实时生效（壁纸模式下渲染引擎常驻，滑动即时预览）
```

### 2.2 配置复制（双模式独立参数）
```
【页面2】→ 当前处于"桌面壁纸模式"
 → 点击 [复制当前配置到全屏模式] (弹窗确认)
 → 确认后：全屏模式的参数被覆盖为桌面壁纸当前参数
 → 反向操作同理（全屏模式面板中 [复制到桌面壁纸模式]）
```

### 2.3 动效自由组合
```
【页面3 动效控制面板】
 → 基础流体动效组：勾选「流体扰动强度 / 背景平移 / 微旋转 / 色彩渐变 / 全局光晕」
 → 音频联动动效组：勾选「涟漪扩散 / 波形扫动 / 节拍脉冲 / 边缘光震荡 / 明暗起伏 / 频谱径向扩散」
 → 装饰粒子动效组：勾选「漂浮光点 / 散景光斑 / 渐变光带 / 径向光晕 / 四角辉光 / 星点浮动」
 → 每个已勾选动效展开强度 / 速度 / 尺寸滑块 → 实时预览
```

### 2.4 预设管理
```
【页面3】→ [预设管理]
 → 加载：选择官方预设（如「深海弥光」「霓虹节拍」「晨雾」）→ 一键套用
 → 保存：命名当前全部动效参数 → 存为自定义预设
 → 删除：长按自定义预设 → 删除
 → 导入/导出：预设以 JSON 文件形式分享
```

## 三、全屏模式 + 计时器流程

```
打开 App → 切换到【App 全屏模式】
 → 进入全屏沉浸式渲染画面（自动隐藏系统栏）
 → 侧滑呼出控制条（或点按右上角齿轮）→ 进入【页面4 计时器面板】
 → 选择模式：正计时 / 倒计时 / 番茄工作计时器
 → 设置时长（如 25:00）、循环开关、提醒方式（震动/弹窗/提示音）
 → 调整时间文字样式：字号、颜色、透明度、描边、位置（左上/居中/右下/自定义坐标）
 → 设置文字图层层级（顶层 / 流体底层）
 → 点击 [开始] → 计时开始，画面保持流体流动
 → 计时结束 → 按设置触发提醒
 → [一键隐藏UI]：全部控件隐藏，仅剩纯流体画面（再次点击任意处唤出）
```

## 四、故障处理流程

### 4.1 壁纸不更新封面（后台被系统杀死）
```
发现桌面壁纸封面停留在旧封面/纯色
 → 打开 App → 首页 → [一键重启通知监听服务] (弹窗提示"已重启")
 → 播放器切歌一次触发新通知 → 封面恢复
```

### 4.2 国产播放器（QQ音乐等）无法捕获封面
```
帮助页指引：
 → 打开 QQ音乐 → 设置 → 通知设置 → 将锁屏/通知样式改为「系统原生样式」
 → 回到 App 首页 → 确认状态面板已显示歌曲信息
```

### 4.3 壁纸耗电偏高
```
→ 打开 App → 【页面5 杂项】→ 开启【性能模式】
→ 渲染分辨率降低 + 装饰粒子组自动关闭 → 功耗下降
→ 或前往系统设置 → 电池优化 → 允许 FlowLume 后台运行（提升体验）
```
